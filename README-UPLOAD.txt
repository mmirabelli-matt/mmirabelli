MATTHEW MIRABELLI PHOTOGRAPHY - WEBSITE FILES
=============================================

HOW TO PUT THIS ONLINE
1. Open the folder "mmimages-website".
2. Upload EVERYTHING inside it to your web host's public folder
   (usually called public_html, htdocs, www or site).
3. index.html must end up at the top of that public folder, so the
   address becomes  https://yourdomain.com/

   Example:  public_html/index.html
             public_html/press/index.html
             public_html/photos/...

NOTES
- Upload the whole folder contents, not the folder itself, unless your
  host wants the folder at the top.
- The site must sit at the top level of the domain (not inside a sub-folder),
  because the picture and style links start with a slash.
- Nothing to install, no database, no password - these are plain files.
- To change a picture: replace the file inside the "photos" folder using the
  exact same file name.
